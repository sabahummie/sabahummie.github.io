## Project Overview

This project evaluated the collaboration of multi-turn, multi agent collaboration in performing small-molecule drug discovery tasks. The goal of this project is to evaluate models collaborative performance retaining the implicit chemical intuition.

## Objectives

- Improve communication performance for 5G users.
- Reduce interference toward radar systems.
- Integrate the beamforming algorithm with an Open RAN xApp.
- Evaluate the system using an OAI-based 5G testbed.

## Technologies

Python, OpenAirInterface, Open RAN, machine learning, digital beamforming, and software-defined radio.
