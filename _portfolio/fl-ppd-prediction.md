## Project Overview

This project  is developed on a simulated de-centralized setup where isolated client node acts as an isolated clinical institutions presearving non-IID data from being vulnerable to unauthorize access.

## Objectives

- To perform federated learning moel prediction on postpartum depression cohort 
- Investigate the underlying bottlnecks in setting up a privacy preserving de-centralized federated architecture. 
- Adapt optimized global feature selection model rendering it more resouce efficient.
- Improve model performance and generalization capabilities using FedXgbBoosting, a tree based parameter update strategy. 

## Research Outcome

- Engineer a decentralized machine learning system utilizing the Flower framework and XGBoost to evaluate
Postpartum Depression prediction.
- Compute the optimal global feature selection, to maximize computational efficiency and achieve a peak predictive
accuracy of 77.5%.
- Implement a collaborative FedXgbBagging strategy to improving generalization and the AUC to 79%, from the 72%.
- Analyze global model evaluation metrics to assess generalization capabilities, demonstrating a highly stable
convergence trajectory with logarithmic loss dropping to roughly 0.39 and achieving a maximum unseen test
accuracy of 82.5%.
- Develop an evaluation pipeline to assess the model’s classification that achieved an 88.6% overall AUC, 87.5%
precision, and an 82.4% F1 Score.

## Technologies

Python, Flower(FLwr) Framework
