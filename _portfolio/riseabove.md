## Project Overview

This project is a Python Flask application to deliver patient-centered, stress-management modules for
reducing internalized stigma in people with epilepsy.

## Objectives

- Developed RISE ABOVE, a Python Flask application to deliver patient-centered, stress-management modules for
reducing internalized stigma in people with epilepsy.
- Implemented human-subject research protocols for the IRB review process, successfully securing regulatory
approval.
- Analyzed focus group usability survey feedback.
